# AI Knowledge Assistant

An AI-powered Knowledge Assistant built using React, FastAPI, and FAISS.

## Features
- Upload documents (PDF, DOCX)
- Ask questions based on documents
- Retrieval-Augmented Generation (RAG)
- Clean and structured answers

## Tech Stack
- Frontend: React + Tailwind
- Backend: FastAPI
- Vector DB: FAISS
- AI: Transformers

## How to Run

### Backend
cd backend
venv\Scripts\activate
uvicorn main:app --reload

### Frontend
cd frontend
npm run dev
